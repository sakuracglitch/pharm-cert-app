# 認定資格・単位管理 PWA v1.4

v0.13を基準に、日常利用できる完成版として整理したPWAです。

## v1.4で追加・改善した点

- アプリ名・画面上の試作版表記を整理
- PWAとしてホーム画面から独立表示
- オフライン起動用Service Worker
- 研修・単位・設定データの主保存先をIndexedDBへ移行
- v0.13までのlocalStorageデータを初回起動時に自動移行
- データ形式のバージョン管理（schemaVersion）
- データ形式更新時の移行前スナップショットをIndexedDB内に保持
- JSONバックアップ書き出し / 読み込み
- 同じURLでアプリ本体を更新した場合、入力済みデータを維持
- 設定画面でアプリバージョンと保存方式を確認可能
- Service Workerはオンライン時に最新版を優先し、オフライン時はキャッシュを利用

## データ更新の考え方

アプリ本体とユーザーデータを分離しています。

1. アプリ本体をv1.1、v1.2…へ更新
2. 同じURLへ新しいファイルを配置
3. 端末内のIndexedDBはそのまま維持
4. データ構造が変わる場合は `schemaVersion` を上げ、`migrateData()` で旧データを変換

v0.13までのデータが同じブラウザ・同じURLのlocalStorageに残っている場合、v1.1初回起動時に自動でIndexedDBへ移します。

## バックアップ

設定 → データ → 「バックアップを書き出す」からJSONを保存できます。
機種変更や大きな更新の前には、念のためJSONバックアップを1つ取る運用を推奨します。

## PWAとして利用する条件

PWAのService WorkerはHTTPS（またはlocalhost）で配信した場合に動作します。
固定URLへこのフォルダ一式を配置し、iPhoneのSafariで開いて「ホーム画面に追加」してください。

## 現在の機能

- 病院薬学認定薬剤師の単位・年度・領域・項目管理
- 研修記録 / 編集 / 履歴
- 項目別取得一覧
- 申請計画（開始年度 → 対象3年度 → 申請予定年度）
- 単位配分シミュレーション / 手動配分 / 一括確定
- HOPESS照合ON/OFF設定
- HOPESS / シクミネット / 日病薬公式リンク
- ボルドー / ティールテーマ、ダークモード
- 目標資格の追加用拡張枠
- 学会プログラム登録UI（自動OCRは今後更新対象）

## 注意

HOPESSの自動ログインや非公開APIへの接続は行いません。
画像（PNG/JPEG/WebP）はTesseract.jsによる日本語+英語OCRに対応します。読取結果は必ず元資料と照合してください。


## PDF・画像読取
- テキスト情報を含むPDFはブラウザ内で解析し、I-1〜V-3と単位数を候補として抽出します。
- 元PDFの掲載順を維持します。
- 自動認識できない区分・単位数は行ごとの「編集」から手動修正できます。
- PNG/JPEG/WebP等の画像はOCR対象です。画像スキャンだけのPDFはページ数が多い場合の負荷を避けるため自動OCR対象外です。必要ページを画像として読み込んでください。
- PDF.js はCDNから読み込みます。PDFファイルそのものを外部サーバーへ送信する処理はありません。


### 読取改善
- 表で「1単位」が研修項目コードの左側にある場合も拾えるように単位対応付けを改善しました。
- 単位数が前後の行に分離された場合も近接行から補完します。
- 画像OCRは初回にOCR用データを取得するため通信環境によって時間がかかります。


### 表形式PDFの単位継承
- 表の各行に単位数が繰り返されず、セクション見出しに「単位数：各1単位」「各0.5単位」とまとめて記載されるPDFに対応しました。
- セクション見出しの単位数を、そのセクション内で単位数が省略された研修項目へ自動適用します。
- 行内に0.5単位等が明記された例外（複数区分を含む行）は、行内の明記を優先します。


### v1.4 単位表ページの優先解析
- PDF全ページをそのまま研修一覧化せず、「単位に関するご案内」「研修項目」「病院薬学単位・研修科目」「単位数」などを手掛かりに単位表ページを探します。
- 「単位に関するご案内」を検出した場合、その直後の単位表ページを優先し、抄録本文に入った後は解析を打ち切ることで誤認識と処理負荷を減らします。
- 「単位数：各1単位」「単位数：各0.5単位」のようなセクション共通単位を各行に引き継ぎます。
- 行内に `II-4 0.5単位 / II-5 0.5単位` のような個別指定がある場合は、共通単位より個別指定を優先します。
- 日本語ローマ数字（Ⅰ〜Ⅴ）、全角ダッシュ、表内で前後行に分離した単位表記を正規化して読み取ります。

### v1.4 研修履歴の一括削除
- 履歴 → 研修履歴 → 「選択」から複数の研修を選べます。
- 「すべて選択」にも対応します。
- 選択した研修をまとめて削除できます。削除前に件数と明細数を確認します。
- 削除された研修に紐づく手動配分・確定済み配分も同時に削除し、孤立データを残しません。
